## 一言でいうと

**`harness-creator`**: 新しいプロジェクトを作るときに、そのプロジェクトに合ったハーネスを作ってくれる skill。
Anthropic の `skill-creator` が skill を作って改善するのと同じように、ハーネスを作って改善する。

## なぜ作るか

- プロジェクトごとに、同じような指示（規約、手順、注意点）をエージェントに書き直している
- とはいえ、全プロジェクト共通のテンプレートをそのまま使うと、プロジェクトに合わない部分が出る
- エージェントの同じミスを何度も手で直している
- TODO: 自分が今困っていることを追記

## どう作るか（方針）

- **枠組み**: どんな部品でハーネスを組むか、プロジェクトに応じてどこまで入れるかを決めておく → `skills/harness-creator/references/framework.md`
- **共通の概念**: 言語や分野が違っても、どのプログラムにもある概念（実行、検証、構造、境界、データ、設定、エラー、ログなど）を一覧にしておく。skill はこれを元にプロジェクトを調べ、足りない情報を聞く → `skills/harness-creator/references/concepts.md`
- **開発ガイドライン**: もともと書いていた、プロジェクトをまたいで使う設計・UI・コーディングの原則。プロジェクトに必要な分だけ入れる → `skills/harness-creator/assets/templates/guidelines/`
- **テンプレート**: 枠組みと概念を元に埋めるひな形 → `skills/harness-creator/assets/templates/`
