## Claude Code 固有

- 実装を終えたら、報告の前に `evaluator` サブエージェントに依頼の内容を渡して確かめさせ、「必ず直す」の指摘を直して、もう一度確かめさせる。文言の修正など、小さな変更では省いてよい <!-- L1 -->
- 多くのファイルを読んで探す作業や Web での調べものは、`Explore` などのサブエージェントに任せ、結論だけを受け取る。読んだ中身が本体の会話に入らないため
- ファイルは `Write` / `Edit` で作成・編集する。スクリプト（Python・`sed`・リダイレクトなど）で書き換えてよいのは、多数のファイルへの機械的な一括変更だけで、そのときは事前に伝え、実行後に formatter と `git diff` で確かめる。スクリプトでの書き換えには、編集後の hook と権限の設定が働かず、変更箇所も見えにくいため
